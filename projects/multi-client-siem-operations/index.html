Multi-client SIEM operations

At Alpha Citra Siber Indonesia, I triaged about 20 security incidents per week across three managed clients on a rotating 24/7 SOC shift.

Incident triage

I used Splunk, IBM QRadar, and Wazuh to monitor and triage security incidents across separate client environments. I helped tune detection logic and SIEM settings to improve alert accuracy and reduce unnecessary escalations.

Alert classification and documentation

I documented the team’s alert classification standards so analysts could apply them consistently across shifts. I also contributed technical documentation for Splunk implementation.
